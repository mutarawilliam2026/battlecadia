# TMDB poster intents

Each prompt was translated into a TMDB Discover query for movies released from
January 1 through December 31, 2026. Results were sorted by popularity, and the
first two results with poster artwork were saved.

- `prompt-1-toy-story-5.jpg` — *Toy Story 5*

TMDB genres: Animation, Family, Comedy.
